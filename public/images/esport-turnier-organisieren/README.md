# Bilder: eSport Turnier organisieren (/esport-turnier-organisieren)

Dateien als .jpg, kleingeschrieben, genau so benennen:

```
hero.jpg            Hintergrund im Kopf
format-offline.jpg  Karte „Offline“
format-online.jpg   Karte „Online“
format-hybrid.jpg   Karte „Hybrid“
format-serie.jpg    Karte „Turnierserie“
game-<name>.jpg     optional je Spielekachel, z. B. game-ea-sports-fc.jpg,
                    game-rocket-league.jpg, game-counter-strike.jpg
plattform.jpg       optional: Mockup für „Dein Turnier bekommt ein digitales Zuhause“
```

Empfehlung: Querformat, ca. 2000 px breit, unter 500 KB.
