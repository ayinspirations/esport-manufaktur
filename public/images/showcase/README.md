# Bilder für die Case-Bühne

Hier gehören die Aufnahmen hin, die unter den Best Cases in der
Vollbild-Bühne laufen — als Hintergrund und als Kachel in der Reihe darunter.

Erwartet wird **eine Datei je Case**, benannt nach dessen `id` aus
`components/CaseShowcase.tsx`, kleingeschrieben, mit der Endung `.jpg`:

```

hhn-techday.jpg                     eintracht-frankfurt-ambition.jpg
hhn-gamingland-meetit.jpg           1822direkt-blacki-cups.jpg
naspa-svww.jpg                      itcs.jpg
stadt-muenchen-bfv.jpg              markenfestival.jpg
erazer-expert.jpg                   spobis-brand-summit.jpg
sonax-rocket-league.jpg             holstein-kiel.jpg
ewe.jpg                             plauen-park.jpg

kreissparkasse-boeblingen.jpg       esport-verband-schleswig-holstein.jpg

vfb-turnierplattform.jpg
vr-bank-starnberg-bfv.jpg
winamax-gluecksgefuehle.jpg
```

Die elf Cases mit eigener Unterseite ziehen ihr Bild aus ihrem eigenen Ordner
(`/images/t-systems/hero.jpg` und so weiter) — für sie ist hier nichts zu tun.

**Zuschnitt:** querformat, mindestens 1600 Pixel breit. Das Bild läuft
formatfüllend hinter der Bühne und wird zusätzlich hochkant auf 3:4 für die
Kachel beschnitten; was zählt, gehört deshalb in die Mitte, nicht an den Rand.

**Größe:** unter 300 kB je Datei. Alle Bilder dieser Sektion werden
vorgeladen, sobald die Bühne in Sicht kommt — bei knapp vierzig Cases summiert
sich jedes Kilobyte.

**Kein `.heic`.** Das Format kommt direkt aus dem iPhone, aber außer Safari
zeigt es kein Browser an. Vor dem Ablegen in JPEG umwandeln.

Fehlt eine Datei, läuft der Case auf der dunklen Fläche der Seite statt auf
einem fremden Foto. Die Bühne ist also vollständig, während die Bilder
nachkommen — es ist nichts weiter zu tun, als die Datei hier abzulegen.
